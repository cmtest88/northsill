# northsill.app

The website for **Northsill**, a native BIM application for Windows, and the home of its
beta releases.

- `site/` — the page published at [northsill.app](https://northsill.app) via GitHub Pages.
- **Releases** — the tester installer. Download the latest from the
  [Releases page](../../releases/latest).

Northsill's source is not in this repository.
